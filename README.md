# Quran Translations

This repository is a local backup and collection of Quran translations sourced from [Tanzil.net](https://tanzil.net/trans/).

## Overview

- **Source:** [Tanzil.net](https://tanzil.net/trans/)
- **Format:** Plain text verse-by-verse (`surah|ayah|text`)
- **Metadata:** Available in [`metadata.json`](metadata.json)

## Notes & Modifications

- **Spelling Corrections:** Custom spelling corrections have been applied to `translations/ur.jawadi.txt` (Urdu - Allama Zeeshan Haider Jawadi).
